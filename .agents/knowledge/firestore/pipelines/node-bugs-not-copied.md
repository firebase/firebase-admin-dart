# Node.js

The `@google-cloud/firestore` version that the golden fixtures capture sends some Pipeline requests that the backend rejects, or that drop or misapply options.[^node-pipelines] Two examples:

- A search-space list holding expressions is sent as a literal `arrayValue` that contains a field reference.
- Variadic `add` and `multiply` are sent as one call with every operand.

# Dart

Dart sends what the backend accepts. For the examples above, it sends an `array(...)` function, and nested two-operand calls such as `add(add(a, b), c)`.[^pipeline-source]

Each such difference is an entry in `_knownDivergences` in `pipeline_golden_test.dart`. The entry gives the reason and a `_Divergence.check` that asserts the shape Dart sends. That table is the full list.[^known-divergences]

# Why

The maintainers' stated reasons are in each `_knownDivergences` entry, usually as the backend's error. For example, Node's literal array draws "Value type is not supported: FIELD_REFERENCE_VALUE", and the variadic call fails because the backend takes exactly two operands.

# Rules for agents

- **Must:** keep Dart's wire format where it differs on purpose. A new divergence needs a `_knownDivergences` entry with a reason, ideally a backend error, and a check.
- **Must not:** "fix" a divergence back to Node's wire format.
