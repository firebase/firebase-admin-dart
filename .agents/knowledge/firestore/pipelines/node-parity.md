# Decision

Firestore Pipelines are checked against Node by machine, in CI. No other product has golden parity tests.

- **Wire format.** `pipeline_golden_test.dart` compares every Pipeline request Dart sends with golden `ExecutePipelineRequest` fixtures. The fixtures are generated by the `@google-cloud/firestore` version pinned in `tool/pipeline_golden/package.json`.[^golden-test] `.github/workflows/pipeline_golden.yml` regenerates them and fails when the committed ones are stale.[^golden-readme]
- **API signatures.** `pipeline_api_parity_test.dart` compares the Dart Pipeline API with a snapshot of the pinned Node SDK's typings.[^api-parity-test] `.github/workflows/pipeline_api_snapshot.yml` fails when the snapshot is stale.[^api-snapshot-workflow]
- **One implementation.** `pipeline_single_implementation_test.dart` requires the static, fluent, top-level and alias forms of each Pipeline function to forward to one implementation.[^single-implementation-test]
- **Live coverage.** `pipeline_e2e_coverage_test.dart` requires every public Pipeline member to have a case in the live E2E suite.[^e2e-coverage-test]

The four tests run in the ordinary unit run. The golden and parity tests list the allowed differences from Node in tables, each entry with a reason. Every entry is checked, and a stale entry fails the test.

# Why

The maintainers' stated reasons:

- "The expected requests come from the Node SDK itself, never from this package, so a test cannot pass by asserting our own output." (`tool/pipeline_golden/README.md`)
- Hand-written unit tests and review missed Pipeline API mismatches, such as an optional `join()` delimiter, and many wire-format bugs.
- When the static and fluent forms were implemented separately, they drifted apart.

# Rules for agents

- **Must:** when you bump the pinned Node SDK, regenerate the fixtures and review the diff.
- **Must not:** edit the fixtures by hand.
- **Must not:** add a Pipeline API without a golden case.
- **Must not:** list a known divergence without a reason. Stale entries fail the test.
